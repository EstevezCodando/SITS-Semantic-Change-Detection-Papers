# Guia de navegação

1. Comece em [[00_Inicio]] e escolha um mapa em `01_Mapas`.
2. Os mapas apontam para **conceitos** (notas de dado, preparo, método, validação e monitoramento). Cada conceito traz uma tabela com os artigos que o utilizam, a relação e as páginas.
3. Cada artigo (`02_Artigos`) tem as mesmas 12 seções e separa *evidência do artigo* de *interpretação*.
4. Para comparar estudos use [[Matriz_Comparativa]], sem classificar superioridade entre bases diferentes.
5. Para investigar uma nota, abra o **grafo local** (profundidade 1 ou 2). Veja [[Guia_Grafo]].
6. Os Canvas mostram o fluxo Dados → Preparação → Métodos → Validação → Resultados → Monitoramento.

## Convenções

- `status_leitura`: *lido (profundo)*, *lido (parcial)* ou *extraído automaticamente (não lido)*.
- “não informado”: o texto convertido não trouxe a informação (ou a busca automática não a encontrou).
- Páginas (p. N) são as do PDF; § indica seção. Itens “detectado automaticamente” devem ser conferidos na página.
- Novos artigos: copie `99_Templates/Template_Artigo.md`.
