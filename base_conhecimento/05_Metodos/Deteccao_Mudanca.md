# Detecção de mudanças

**Natureza:** tarefa. A base distingue algoritmo, arquitetura, ferramenta, tarefa, etapa metodológica, dado e desenho de validação por este campo.

> *Definição, pressupostos e limitações* abaixo são **interpretação/conhecimento geral da base**, salvo onde há token de página. Os fatos dos artigos estão na tabela de evidências.

## Definição

Identificar onde a superfície mudou entre datas.

## Finalidade

Identificar onde a superfície mudou entre datas.

## Entradas

Imagens de duas ou mais datas corregistradas.

## Saídas

Máscara binária de mudança ou mapa de transições.

## Pressupostos

Dados comparáveis entre datas (radiometria e geometria).

## Limitações

Binária não diz o que mudou; segmentação de uma imagem isolada não é evidência de mudança temporal.
